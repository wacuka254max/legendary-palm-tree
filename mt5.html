One Expert Advisor that trades forex and Volatility Indices automatically on your own MetaTrader 5 terminal. Install it once on a single chart and it handles the rest.

1

Get it running

Free for our Deriv community — a quick check, then the file.
  1. 1Copy the file into MT5’s MQL5/Experts folder — find it via File → Open Data Folder.
  2. 2In MT5 go to Tools → Options → Expert Advisors, tick Allow WebRequest and add https://www.pipvana.com.
  3. 3Restart MT5, or press Compile in MetaEditor. The bot then appears under Expert Advisors.
  4. 4Drag it onto any one chart, set InpProfile to your risk level, and enable Algo Trading — the toolbar button must be green: Algo Trading is on, Algo Trading is off.
  5. 5(Recommended) Right-click the bot → Register a Virtual Server so it keeps trading with your computer off.
  6. 6Make sure you have followed every step above, in order. A skipped step — the WebRequest address, Algo Trading, the risk profile — is the usual reason a bot sits idle.

You keep full custody — it runs on your own terminal and we never see a password. Once it is set up it needs nothing further from this page.
